## Notes

Sometimes is not enough to know category expenses. It will be nice if user will be able to add subcategories.
Then on dashbord chart will stay as it is but table can show information about category as sum of it subcategories.
Something like below:

| Category       | Expense |
|----------------|---------|
| cat_1          | 111     |
| cat_2          | 333     |
|   -> sub_cat_1 | 111     |
|   -> sub_cat_2 | 111     |
|   -> sub_cat_3 | 111     |
| cat_3          | 32      |

Additionally user need to have an option to add budget to subcategories.
